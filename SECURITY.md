# Security Policy

## Supported Versions
We actively support and patch the latest major release of LightScan Trust Engine.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
Please do not open GitHub issues for security vulnerabilities. Instead, report them privately by emailing **zaceswin4@gmail.com**.

We will acknowledge receipt within 48 hours and provide a status update along with a target fix date.
